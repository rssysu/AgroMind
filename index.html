AgroMind

Benchmarking Large Multimodal Models in Agricultural Remote Sensing

GitHub GitHub Pages Paper (arxiv) Dataset

Abstract

Large Multimodal Models (LMMs) have demonstrated capabilities across various domains, but comprehensive benchmarks for agricultural remote sensing (RS) remain scarce. Existing benchmarks designed for agricultural RS scenarios exhibit notable limitations, primarily in terms of insufficient scene diversity in the dataset and oversimplified task design. To bridge this gap, we introduce AgroMind, a comprehensive agricultural remote sensing benchmark covering four task dimensions: spatial perception, object understanding, scene understanding, and scene reasoning, with a total of 13 task types, ranging from crop identification and health monitoring to environmental analysis. We curate a high-quality evaluation set by integrating nine public datasets and one private global parcel dataset, containing 28,482 QA pairs and 20,850 images. The pipeline begins with multi-source data pre-processing, including collection, format standardization, and annotation refinement. We then generate a diverse set of agriculturally relevant questions through the systematic definition of tasks. Finally, we employ LMMs for inference, generating responses, and performing detailed examinations. We evaluated 20 open-source LMMs and 4 closed-source models on AgroMind. Experiments reveal significant performance gaps, particularly in spatial reasoning and fine-grained recognition. Notably, human performance lags behind several leading LMMs. By establishing a standardized evaluation framework for agricultural RS, AgroMind reveals the limitations of LMMs in domain knowledge and highlights critical challenges for future work. Data and code can be accessed at https://rssysu.github.io/AgroMind/.

Key Contributions

Comprehensive Dataset

  • 9 public datasets + 1 private global parcel dataset
  • 20,850 high-quality images
  • 28,482 diverse QA pairs
  • Multi-sensor integration (UAV, Satellite, Camera)

Multi-dimensional Benchmark

  • 4 evaluation dimensions
  • 13 task types
  • Spatial perception to scene reasoning
  • Real-world agricultural scenarios

Extensive Evaluation

  • 20 open-source LMMs evaluated
  • 4 closed-source models (GPT-4o, Gemini, Claude)
  • Human performance comparison
  • Detailed task-level analysis

Evaluation Dimensions

Hierarchical task system covering 4 dimensions and 13 task types

Key Findings

  • Spatial Perception: Models struggle with spatial reasoning tasks like Boundary Detection (BD)
  • Object Understanding: High accuracy on Object Classification (OC) but low on Growth Status Recognition (GSR)
  • Scene Reasoning: Models excel at Climate Type Reasoning (CTR) using broad knowledge
  • Human vs AI: GPT-4o outperforms humans by 9.99% overall, but lags in spatial perception tasks

Dataset Details

The AgroMind dataset was compiled from three sensor types:

  • Unmanned Aerial Vehicles (UAVs): 7,000 QA pairs
  • Satellite platforms: 12,000 QA pairs
  • Ground-based cameras: 9,000 QA pairs

Covering five critical agricultural categories:

  • Anomaly Detection
  • Crop Monitoring
  • Pest Identification
  • Parcel Delineation
  • Tree Analysis
